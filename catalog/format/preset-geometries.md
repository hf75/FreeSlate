# Preset geometries

From `presetShapeDefinitions.xml` and `presetTextWarpDefinitions.xml` (ECMA-376 Part 1). Every preset is defined
by adjust values, guide formulas, handles, connection sites and paths, so a renderer can evaluate all of them
with one formula engine instead of hand-written code per shape.

- `a:ST_ShapeType` lists 187 values, the data file has 187 definitions: no definition for `upArrow`; defined twice: `upDownArrow`.

- `a:ST_TextShapeType` lists 41 values, the data file has 40 definitions: no definition for `textNoShape`.
