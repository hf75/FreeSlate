The files are included unchanged. `presetShapeSupplement.xml` is ours and adds the definitions the file lacks.

`builtinTableStyles.xml` holds the definitions of PowerPoint's 74 built-in table styles as PowerPoint writes them into
`ppt/tableStyles.xml` of the presentations that use them (generated by applying each style to a table and saving;
style names translated to English). Files from other producers may name a built-in style without defining it; the
renderer then takes its definition from here.

`cmykToRgb.bin` holds the colors PowerPoint shows for CMYK pictures without a color profile of their own: 9⁴ CMYK
patches (levels 0, 32, … 255; RGB triplets, cyan varying slowest and black fastest) measured from PowerPoint's
rendering of a patch chart by `dotnet run --project tools/Fidelity -- harvest-cmyk`.
